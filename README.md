This Android application is designed to take input from the user and display a welcome message. The app contains a simple user interface with a text field where the user can enter their name and a button to submit the input.
When the user enters their name and clicks the button, the application displays a Toast message saying “Welcome, [User Name]” on the screen. This helps in understanding user input handling and basic event handling in Android.
The project demonstrates the use of:
EditText (for name input)
Button (to trigger action)
Toast (to display message)
Basic Java/Kotlin event handling

This Android application is a basic calculator designed to perform simple arithmetic operations. The app provides a user-friendly interface where users can enter two numbers as input and perform calculations such as addition, subtraction, multiplication, and division.
The interface includes two input fields (EditText) for entering numbers and four buttons representing the operations (+, −, ×, ÷). When the user clicks any operation button, the app processes the input values and displays the result on the screen using a TextView or Toast message.
This project helps in understanding:
Taking user input using EditText
Handling button click events
Performing arithmetic operations in Java/Kotlin
Displaying output dynamically
Overall, this calculator app is a beginner-friendly project that demonstrates basic UI design, event handling, and logic building in Android development.

This Android application is designed to collect user preferences about mobile devices and their features. The app provides an interactive interface using Radio Buttons and Check Boxes.
The user can first select their device type (such as Android, iOS, or others) using Radio Buttons, where only one option can be selected at a time. Then, the user can choose multiple features (such as Camera, Battery, Storage, Performance, etc.) using Check Boxes, allowing multiple selections.
After selecting the device and features, the user clicks a submit button, and the application displays the selected options using a Toast message or TextView.
This project helps in understanding:
RadioGroup and RadioButton (single selection)
CheckBox (multiple selection)
Handling user input and events
Displaying selected data dynamically
Overall, this assignment is useful for beginners to learn how to manage multiple input components and build interactive Android applications.
